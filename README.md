# Mapping-excel-data-to-google-maps
Mapping Excel Data to Google Maps

# Tools Used:
Microsoft Excel
Google My Maps
Google Sheets

# Project Overview:
This project demonstrates how to import Excel data (such as names, addresses, cities, and states) into Google My Maps for geographic visualization. The data was cleaned and structured in Excel, then uploaded to My Maps to create interactive map layers. Each marker represents a specific location, with color coding applied to distinguish data types or regions.

# Steps Performed:
Prepared and cleaned data in Excel (Name, Address, City, State).
Combined address fields into one column for geocoding.
Imported the CSV file into Google My Maps.
Customized map layers and marker styles.
Exported and shared the map link for analysis.

# Key Skills:
Data visualization | Mapping | Excel data cleaning | Google Maps | GIS Basics

# Outcome:
Improved visualization of geographic data, making it easier to identify patterns, clusters, and relationships between different locations.
